# Atom Eats Order Hub

Internal order website for Atom Eats offline orders, at https://orders.atomeats.com.

- Website: React + Vite + Tailwind, published to GitHub Pages on every push to `main`.
- Data: a separate Supabase project (`atom-eats-order-hub`). Keys live in GitHub secrets, never in this repo.
- Real business files (POs, customer lists, chats) are kept outside this repo.
